Active ton assistant.

Gratuit avec Google Gemini : il suffit d'un compte Google, sans carte bancaire. (Une clé Claude payante, qui commence par sk-ant-, marche aussi.)

  1. Va sur aistudio.google.com/apikey et connecte-toi avec ton compte Google.
  2. Clique sur Create API key, puis sur Copy (la clé commence par AIza ou AQ.).
  3. Colle la clé ci-dessous (Ctrl + V, ou Cmd + V sur Mac) et clique sur Activer. Elle reste uniquement sur cet ordinateur.
